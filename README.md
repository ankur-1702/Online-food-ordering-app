# Online Food Delivery Application (Frontend)

## Overview
This is a **React-based frontend** for an online food delivery application. The app enables users to **browse menus, add items to a cart, sign in/up, and place orders**. The focus is on a **responsive, interactive, and componentized UI** that provides a smooth user experience.

---

## Tech Stack
- **Frontend:** React.js (Functional Components, Hooks)  
- **Routing:** React Router  
- **State Management:** React Context API (for cart and user data)  
- **Styling:** CSS  
- **Build Tool:** Vite  
- **Assets:** Images, icons, and fonts stored in `public/assets`  

---

## Features
1. **Home / Menu Page**
   - Displays categories and food items dynamically.  
   - Users can browse items, filter by category, and view details.  

2. **Cart**
   - Add/remove food items.  
   - Shows total price and order summary.  
   - Integrates with global state using Context API.  

3. **Authentication**
   - Sign Up / Sign In forms.  
   - Basic frontend validation implemented.  

4. **Place Order**
   - Users can place orders and view order confirmation.  
   - UI feedback ensures smooth interaction.  

5. **Responsive Design**
   - Works across desktop and mobile devices.  
   - Interactive buttons, modals, and forms optimized for UX.
